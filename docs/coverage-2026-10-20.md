Reproduce with the repository development environment (all builds/tests under `nice`; language compilation and hardware checks outside the sandbox):

```sh
export PYTHON_CPU_COUNT=1
nice uv run pytest tests/test_assemble.py tests/test_refs.py tests/test_extended_autocases.py tests/test_evidence.py
nice uv run sass-build-languages --generate-only --coverage
for arch in SM75 SM80 SM86 SM89 SM90 SM100 SM101 SM103 SM107 SM120; do
  nice uv run python -m tests.autocases "$arch" --write
  for fp in exact readable; do
    nice uv run pytest tests/test_lifted_semantics.py tests/test_family_lowering.py --family fp32 --arch "$arch" --fp "$fp"
  done
done
nice uv run sass-build-languages
for arch in SM75 SM80 SM86 SM89 SM90 SM100 SM101 SM103 SM107 SM120; do
  for fp in exact readable; do
    nice uv run pytest tests/test_pcode_semantics.py -m ghidra --family fp32 --arch "$arch" --fp "$fp"
  done
done
nice uv run pytest -m gpu --require-gpu --family fp32
nice uv run sass-refresh-coverage
python3 .github/scripts/coverage_comment.py local 5d8f17bac1439bc3b7a811d3dfc007e32abaf481
```

In this 2-core/8-GiB workspace, architecture/lowering runs were split into individual processes and coverage refresh was staged into manifest generation, per-architecture evidence collection, and the standard coverage writer. All generated coverage artifacts use the canonical generator and renderer.

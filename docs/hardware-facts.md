# GPU semantics oracle and SM89 hardware facts (Phase 5)

- `pytest tests -m gpu --require-gpu` compiles the SM89 fixture kernels, verifies target mnemonics are executed, runs the GPU via ctypes CUDA Driver API, and compares whole-kernel Ghidra `PcodeEmulator` outputs for 128 random/edge vectors each.
- `src/sass/decode/cubin.py::kernel_image` reads actual text, constant sections and CUDA parameter metadata. The harness seeds bank 0 launch dimensions, metadata-defined pointers, and named TID/CTAID registers. It runs independent threads from entry to EXIT, with PC bounds and an instruction budget. GPU access works outside the sandbox.
- Cooperative fixtures (`Fixture(cooperative=True, block=N)`): one `BlockEmulator` per block, warps in lockstep, SHFL/VOTE gathered across lanes, BAR.SYNC as a whole-block barrier; details in `tests/README.md`.
- Hardware-established SM89 behavior: PRMT SASS source order is data A, selector, data B. F2I.TRUNC.NTZ to S32 returns 0 for NaNs and clamps infinities/finite overflow. Other NTZ formats/modes remain unsupported. Implicit memory descriptor forms use ordinary global/local pointers; explicit descriptors remain opaque. Shared-memory X4 addressing scales the base register without changing its value.
- More SM89 hardware facts (2026-10-13, GPU fixtures in `tests/cases/conversions.py`, `fp32.py`, `predicates.py`):
  - FCHK.DIVIDE Pu, a, b depends only on the biased exponents: `ea <= 24 or ea == 255 or eb <= 1 or eb >= 252 or ea - eb >= 127 or eb - ea >= 125` (signs, mantissas and |x|/-x ignored; 0 mismatches on 1.1M pairs incl. every boundary cell).
  - F2I saturates in every mode; a NaN gives 0 with .NTZ (ptxas emits it for 32-bit destinations from F32/F16) and the destination's top bit otherwise (0x80000000, 0x8000000000000000, also for U64). .FTZ flushes a denormal input (CEIL of +denormal: 1 without, 0 with).
  - FRND rounds to an integral value keeping a zero's sign; an F32 NaN gives 0x7fffffff, an F64 NaN keeps its payload, quieted. F2F keeps a NaN's sign and payload (aligned to the top of the fraction), quieted. I2F is exactly rounded in all four modes; an F16 result is zero-extended in Rd.
  - PLOP3 with Pu == Pv writes Pu's value.
- Floating comparisons are exact except NaN payload/sign. MUFU approximation, device calls/returns, barrier reductions and divergent warps are not hardware-verified here. Hardware-verified multi-thread forms (2026-10-14, all lanes active): SHFL IDX/UP/DOWN/BFLY follow PTX shfl.sync exactly (524288 lane results with random b and c; UP's bound `(lane & seg) | (clamp & ~seg)` is a lower bound, the other modes check only `j <= bound`, so BFLY may leave the segment downward; b's bits above 4 and c's other bits are ignored), VOTE ANY/ALL/EQ and the ballot, and shared memory across BAR.SYNC between four warps. Scalar fixtures keep shared memory thread-private; BSSY/BSYNC are acknowledged for independent scalar loop execution.

- Native carry chains include IADD3.X (two predicate inputs), LEA LO/HI/SX32 with .X, and IMAD LO/HI/WIDE .X, including uniform aliases. IADD3 Pu/Pv are unary thresholds at 2^32/2^33; Pu wins aliased outputs. Ordinary negation preserves the 33-bit +1; .X uses complement plus predicate inputs. LEA selects its shifted low/high word before modifiers. IMAD HI/WIDE carry reports unsigned overflow of the full 64-bit product-plus-addend. Ra/Rb cannot both be modified for IADD3/LEA. The carry GPU fixtures (`tests/cases/carry.py`) check patched whole kernels against independent integer references and actual Ghidra p-code; SM89 evidence does not establish other architectures on hardware.
